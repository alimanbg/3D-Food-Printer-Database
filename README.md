# 3D-Food-Printer-Database
Developed the database for a 3D food printer prototype that customizes meals based on users’ nutrition goals, dietary needs, and budget. Designed SQL tables linking users, recipes, ingredients, and printers to support personalized, data-driven meal printing.

During a hackathon, our team designed a smart 3D food printing system that personalizes meals according to each user’s nutritional requirements, preferences, and financial constraints. I was responsible for building the SQL database architecture, creating interrelated tables for users, their nutrition targets, recipes, ingredients, and printers. The schema supported dynamic recipe generation, user-specific nutrition tracking, and printer job management. By integrating nutritional data with recipe composition and printer control, the database enabled automated meal planning and printing based on calorie goals, macronutrient ratios, and ingredient availability. This project showcased how database design can power intelligent, health-oriented food technologies combining personalization, automation, and nutritional science.
